# AI Usage Statement

**Name:** Josue Castillo  
**Course:** CS 3354 – Object-Oriented Programming  
**Project:** Console-Based Chess Game – Phase 1  
**Assigned Classes:** `Game.java` and `Player.java`  
**AI Tool Used:** ChatGPT (OpenAI)

## How I Used AI

Throughout this project, I used ChatGPT to help me understand the assignment requirements, organize my responsibilities, and work on my assigned Java classes.

I first used ChatGPT to break down the project instructions and grading rubric so I could understand what needed to be completed for each milestone. I also used it to help create the initial structure of my Game and Player classes, including their attributes, methods, and Javadoc comments.

When I started implementing the methods, I used ChatGPT to help write and understand the game logic, such as initializing players, managing turns, reading player input, and ending the game.

I also used ChatGPT to help identify errors and compatibility issues between my code and my teammates' classes. One example was when the suggested code used `Color.WHITE` and `Color.BLACK`, but our team's Color class used strings instead. I used ChatGPT to correct this by using `new Color("white")`, `new Color("black")`, and the existing `isColor()` method.

Additionally, I asked ChatGPT to generate a standalone `Main.java` file to demonstrate how two players could enter moves in the console. This was useful as a reference for understanding the overall gameplay, but it was separate from our team's object-oriented implementation.

## What I Learned

Using ChatGPT helped me better understand how different Java classes interact with each other. I gained a better understanding of constructors, private attributes, method calls, and how the Game and Player classes communicate with the Board class.

I also learned that AI-generated code does not always match an existing project. Some of the suggested methods and attributes had to be adjusted to follow the structure my teammates were using.

## My Contribution

My main responsibility was working on `Game.java` and `Player.java`. I used ChatGPT as a resource for planning, generating initial code, understanding methods, and troubleshooting errors. The AI-generated suggestions were not always immediately compatible with our project, so they required review and adjustments.

Overall, ChatGPT was helpful throughout the development process, especially when I needed explanations or help identifying problems in the code.
